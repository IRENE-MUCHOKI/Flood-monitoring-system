# Flood-monitoring-system

It is a low-cost prototype designed to monitor water levels during floods. It uses an ultrasonic sensor to measure the distance between the sensor and the water surface, an arduino to process the measurements and activate the LEDs and a buzzer.

# Objectives
Monitor changes in water levels in real time.
Identify different water-level risk conditions.
Provide visual and audible alerts.
Demonstrate an affordable approach to flood monitoring.

# Components Used
HC-SR04 Ultrasonic Sensor
Green, Red and Yellow LEDs
Buzzer
Arduino UNO
Resistors
Jumper cables
